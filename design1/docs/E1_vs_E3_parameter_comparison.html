Key Differences Summary:

  • Probe Count: E1 uses 20 probes vs E3's 30 probes
  • Simulation Count: E1 runs 2000 simulations vs E3's 100 (due to different test types)
  • Copying Parameter: E1 uses c=0.885 vs E3's c=0.70
  • Reinstatement Rate: E1 uses 0.1 vs E3's 0.2
  • Initial Criterion: E1 uses 0.65^(1/11) vs E3's 0.148^(1/11)
  • List Origin Parameters: E1 has specific z-parameters for list origin recall, E3 uses recall-to-reject parameters
  • Context Testing: E1 tests limited context initially, E3 tests all context
