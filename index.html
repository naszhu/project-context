Project-Context

Central Hub for Experimental Designs & Documentation

About This Project

Project-Context serves as the central repository coordinating multiple design iterations, data analyses, modeling workflows, and UI experiments for our research. It underpins specialized child repositories like the rem_e3_model_fixed module.

📂 Folder Structure

  • Docs/ — Documentation: meeting notes, IRB approvals, literature reviews
  • design1/, design2/, design3/ — Each design’s assets:
    • data/ — raw & processed data
    • data_analysis/ — analysis scripts & notebooks
    • modeling/ — code & models (E3 model)
    • ui_experiment/ — front-end experiment code
  • exp_host/ — Latest modular JS host for online experiments
  • papers/ — Key literature & references
  • .github/ISSUE_TEMPLATE/ — Issue templates

🚀 Getting Started

Clone and explore:

git clone https://github.com/naszhu/project-context.git
cd project-context

Navigate to subfolders for specific workflows and instructions.

🐛 Issue Tracking

All project issues are managed via GitHub Issues. Current focus on Design 3. See Issues tab.

🔗 Child Repositories

  • rem_e3_model_fixed — E3 model code & simulations

🏷️ Versioning & Conventions

Commits follow type(scope): message format. Development is currently on main. Stable releases are tagged in child repos.
