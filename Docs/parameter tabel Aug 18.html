Research Parameters - E3 vs E1 Comparison

How the Model Works

Storage and Retrieval

Items are stored using two key parameters:

  • u_star: Controls how much information gets stored initially
  • c parameter: Controls how well information is copied during storage

Restoration During Test

During testing, traces are restored in two ways:

  • New traces: Restored the same way they were studied
  • Strengthening traces: Strengthen the recalled trace and strengthen the values that were missing. Restored with higher values than when studied (controlled by u_star for strengthen and c for strengthen)

Context Deterioration

Context features change in several ways:

  • Between study and test: Features drift/deteriorate during the delay
  • Between each item during test: Features continue to change as testing progresses
  • Between lists: Features change as new lists are presented

Key Probabilities

  • Drift between study and test: 30.6% (E3) vs 28.0% (E1)
  • Reinstatement during test: 20% (E3) vs 10% (E1)
  • Change between lists: 42.2% for both experiments

Decision Making

The model uses criteria and thresholds to make recognition decisions. Experiment 3 uses a recall threshold (0.899) while Experiment 1 does not (0.0). This threshold helps E3 predict confusing foils better by slightly shifting performance down, which aligns better with the data.

Recall-to-Reject Mechanism

This is a product term that combines:

  • The probability of using recall-to-reject information
  • The probability of answering "new" when recalling list of origin

Each item type is controlled by three parameters:

  • How much: The magnitude of the shift
  • How fast: The rate of asymptotic change between lists
  • Starting value: The initial probability

The exponential formula for the asymptotic increase is: start_at + how_much × (1 - exp(-how_fast × k)) where k ranges from 0 to n-1 (n being the number of lists).

Key Differences Between E3 and E1:

  • n_probes: E3 uses 30 probes, E1 uses 20 probes
  • c parameter: E3 uses 0.70, E1 uses 0.895
  • p_reinstate_rate: E3 uses 0.2, E1 uses 0.1
  • p_driftStudyTest: E3 uses 0.306, E1 uses 0.280
  • criterion_initial: E3 uses 0.148^(1/11) = 0.839, E1 uses 0.65^(1/11) = 0.965
  • recall_odds_threshold: E3 uses 0.3^(1/11) = 0.899, E1 uses 0.0^(1/11) = 0.0
  • z parameters: E1 has simpler z structure with only T and F, while E3 has complex z structure with multiple probe types
