## Probe Type Abbreviations

**Initial and Final Test Probe Types:**

- **ST** = Study-Test: Items both studied and tested in the initial phase
- **SO** = Study-Only: Items studied but not tested in the initial phase
- **TO** = Test-Only: Items presented as foils during testing
- **STn** = Study-Test in list *n*, then foil in list *n*+1 (confusing foil)
- **SOn** = Study-Only in list *n*, then foil in list *n*+1 (confusing foil)
- **TOn** = Test-Only (foil) in list *n*, then foil in list *n*+1 (confusing foil)
- **FTO** = Final Test Only: Never-presented items (new foils)

**Note on Confusing Foils:** Items marked with '*n*' suffix (STn, SOn, TOn) are "confusing foils" that appeared in different roles across consecutive lists, potentially creating proactive interference.
