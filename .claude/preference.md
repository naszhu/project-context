# Claude Code Preferences

## Code Modification Policy

**IMPORTANT: Make ONLY the minimal, essential changes requested.**

When asked to change, move, or refactor code:
- Do NOT modify spacing, indentation, or formatting unless absolutely necessary
- Do NOT change syntax style (e.g., quote styles, semicolons, line breaks)
- Do NOT reformat code to match any style guide unless explicitly asked
- Do NOT add or remove blank lines for aesthetic reasons
- Do NOT reorganize code structure unless it's directly required for the requested change

**Only modify what is strictly essential to fulfill the core request.**

Unnecessary reformatting and style changes cause problems and make diffs harder to review. Stick to the exact changes needed - nothing more.

## Summary
- Minimal changes only
- Preserve existing formatting and style
- Only touch what's necessary for the specific request
